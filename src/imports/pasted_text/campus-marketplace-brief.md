Design and build a CRAZY, premium, futuristic web app for a student-to-student campus marketplace called:

"CAMPUS MARKETPLACE"

Tagline:
"ONE CAMPUS. ONE MARKETPLACE."
"Everything students need, already on campus."

IMPORTANT:
Use the attached reference images as the source of truth for the product concept, problem statement, categories, and overall messaging — but DO NOT copy the visual design. Completely reinvent the UI into a modern, experimental, highly interactive website.

CORE IDEA:
A trusted marketplace exclusively for students within the same college/campus. Students can buy, sell, exchange, reuse, and discover items from people around them.

TARGET AUDIENCE:
College students aged 18–24 who want affordable books, electronics, furniture, hostel essentials, cycles, study materials, and other useful items.

VISUAL DIRECTION:
Make it feel like a combination of:
- futuristic startup landing page
- premium Apple-style product design
- Depop/Vinted marketplace
- modern college culture
- playful Gen-Z internet aesthetic
- subtle 3D elements
- glassmorphism
- bold typography
- smooth animations
- editorial layouts
- interactive cards

The website should feel INSANELY polished and memorable, not like a generic marketplace template.

COLOR SYSTEM:
Primary background: warm off-white / #F8F7F3
Primary text: near-black
Accent: vibrant orange
Secondary accent: fresh green
Use subtle blue/purple accents only for interactive states.
Use orange for important CTAs and marketplace actions.
Keep the overall design clean despite the experimental visuals.

TYPOGRAPHY:
Use a huge bold grotesk/display font for headlines.
Use a clean modern sans-serif for body text.
Very large typography should dominate the hero.
Mix huge text with tiny uppercase labels for an editorial feel.

DESIGN DETAILS:

- Use generous whitespace.
- Use extremely large typography.
- Use rounded cards but avoid making everything look like a standard SaaS dashboard.
- Mix sharp editorial sections with rounded marketplace cards.
- Use subtle grain/noise texture.
- Add thin black/gray borders.
- Use orange accent strokes and hand-drawn arrows sparingly.
- Add subtle shadows.
- Add glass effects for floating UI.
- Use asymmetric layouts.
- Avoid excessive gradients.
- Avoid generic stock photography.
- Prefer product photography, illustrated objects, avatars, and campus-inspired graphics.

INTERACTIONS:
Make the prototype feel alive.

Include:
- smooth scrolling
- hover animations
- cards that tilt slightly on hover
- product cards expanding on hover
- animated marketplace ticker
- floating hero cards
- animated connection lines
- campus map interactions
- filter chips
- search interaction
- sticky navbar
- scroll-triggered animations
- buttons with satisfying micro-interactions
- subtle cursor-following effects in the hero

RESPONSIVE:
Create desktop AND mobile versions.
Mobile should feel intentionally designed, not simply compressed desktop.

MOST IMPORTANT:
The final website should communicate the idea within 3 seconds:

"Students can buy and sell useful things from other students on their own campus."

Make it feel like a REAL startup that could launch tomorrow.

Do not make it look like a school project.
Do not make it look like a generic ecommerce site.
Make it feel bold, youthful, premium, slightly experimental, and extremely polished.
